# Wireframes iniciais do Lume

## Desktop

```text
┌──────────────┬──────────────────────────────┬──────────────┐
│ Lume          │            Feed              │ Descobrir    │
│ Início        │  stories                     │ sugestões    │
│ Seguindo      │  ┌────────────────────────┐  │              │
│ Descobrir     │  │ mídia · legenda · ações │  │              │
│ Criar         │  └────────────────────────┘  │              │
│ Perfil        │                              │              │
└──────────────┴──────────────────────────────┴──────────────┘
```

## Mobile

```text
┌──────────────────────┐
│ Lume             ☼   │
│ stories              │
│ ┌──────────────────┐ │
│ │      publicação  │ │
│ │  mídia / ações   │ │
│ └──────────────────┘ │
│  Início  ＋  Buscar  │
└──────────────────────┘
```

Princípios: conteúdo primeiro, navegação persistente, criação acessível em até um toque e foco em conexões por interesse.
